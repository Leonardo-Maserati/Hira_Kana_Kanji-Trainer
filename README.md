Hira_Kana_Kanji-Trainer

This is a simple Python tool I built to practice Hiragana, Katakana, and some basic Kanji directly in the terminal.

Features

- Random prompts so you don't get the same order every time.

- No back-to-back repetitions of the same character.

- Accuracy tracking for the Hiragana and Katakana modes.

- A simple "reveal" system for Kanji meanings.

- It’s lightweight and doesn't need any extra libraries to run.

How to use it

1. Make sure you have Python 3 installed.

2. Run the script: python jp_script_trainer.py

3. Choose a mode from the menu and start typing the romaji. 

4. You can type "exit" whenever you want to go back to the main menu.

Why I made this

I wanted a quick way to test my memory on Japanese scripts while also practicing my Python skills. It's meant to be a simple, no-nonsense tool.
